# 📊 Finance Analyst Dashboard – Power BI

## 📌 Project Overview

This project presents an interactive **Finance Analyst Dashboard** developed using **Microsoft Power BI** to analyze financial performance and generate meaningful business insights.

The dashboard provides a consolidated view of revenue, expenses, profit, profitability trends, and other financial indicators through interactive visualizations and KPI cards.

The project demonstrates practical skills in **data analysis, data visualization, DAX, Power BI dashboard development, and financial analysis**.

---

## 🎯 Project Objective

The main objectives of this project are to:

* Analyze overall financial performance
* Monitor revenue and expenses
* Evaluate profitability
* Identify financial trends and patterns
* Compare different business segments/categories
* Present financial information through an interactive dashboard
* Generate insights that can support business decision-making

---

## 🛠️ Tools & Technologies

* **Power BI** – Dashboard development and visualization
* **DAX** – Measures and financial calculations
* **SQL** – Data analysis and querying
* **Excel/CSV** – Dataset and data preparation
* **Power Query** – Data cleaning and transformation

---

## 📊 Dashboard Pages

The Power BI report contains **4 interactive pages**.

### 1️⃣ Financial Overview

Provides a high-level summary of the organization's financial performance.

**Key elements:**

* Revenue
* Expenses
* Net Profit
* Profit Margin
* Overall financial performance
* Financial trends

This page is designed as the main management overview.

---

### 2️⃣ Revenue Analysis

Focuses on understanding revenue generation and revenue trends.

**Analysis includes:**

* Revenue trends
* Revenue comparison
* Revenue by category/segment
* Period-wise performance
* Identification of high-performing areas

This page helps understand where revenue is being generated and how it changes over time.

---

### 3️⃣ Profit Analysis

Analyzes the relationship between revenue, expenses, and profitability.

**Analysis includes:**

* Net Profit
* Revenue vs Expenses
* Profitability trends
* Profit Margin
* Profit/Loss comparison
* Identification of profitable and loss-making areas

This page provides a deeper understanding of financial performance.

---

### 4️⃣ Financial Insights

Provides a consolidated view of important financial findings from the analysis.

**Key focus areas:**

* Important financial trends
* High-performing areas
* Low-performing areas
* Profitability observations
* Revenue and expense patterns
* Business-oriented insights

The purpose of this page is to convert dashboard analysis into actionable observations.

---

## 📈 Key KPIs

The dashboard uses important financial KPIs such as:

| KPI                 | Purpose                                    |
| ------------------- | ------------------------------------------ |
| **Total Revenue**   | Measures total income generated            |
| **Total Expenses**  | Measures total expenditure                 |
| **Net Profit**      | Shows financial gain/loss after expenses   |
| **Profit Margin %** | Measures profitability relative to revenue |
| **Revenue Growth**  | Tracks change in revenue over time         |

## 🧮 DAX & Analysis

Key financial calculations were created using DAX, including measures for:

* Total Revenue
* Total Expenses
* Net Profit
* Profit Margin %
* Revenue Growth
* Financial comparisons

These measures were then used to create interactive KPIs and visualizations.
